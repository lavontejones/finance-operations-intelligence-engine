# Limitations

- This is not an accounting system, ERP, payment platform, or production deployment.
- Forecast results are illustrative. They are not financial advice or a forecast of any real company.
- Control rules are small deterministic examples. They need calibration, testing, and finance-owner approval.
- The included API does not persist data. The review endpoint returns a simulated decision only.
- The dashboard is optional and reads synthetic in-memory results.
- The n8n file is inactive and contains no connection credentials.
- Legal intercompany accounting is not modeled. Internal cost-center transfers are only a management-reporting assumption.
